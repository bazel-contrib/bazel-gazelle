# Gazelle v2

Gazelle v2 is currently in development and is expected to be released near the end of 2026. v2 has the following major goals:

1. Revise the extension interface to make it simpler for authors to create new extensions.
2. Enable and simplify development of new features like #2471 and #2472.
3. Speed up incremental runs of Gazelle by enabling lazy indexing by default.
4. Drop support for `WORKSPACE`, `GOPATH`, and the `update-repos` command.

#2207 is the original proposal for v2.

#2272 tracks progress on v2.

To upgrade to v2, select the latest v2 beta version in the BCR.

```starlark
bazel_dep(name = "gazelle", version = "2.0.0-beta.2")
```

To upgrade your extension to the v2 interfaces, use [gazelle-migrate-language](skills/gazelle-migrate-language/SKILL.md) agent skill, or follow the instructions there. See [Extending Gazelle](extend.md) for information on writing extensions.

Gazelle v2 is backward compatible, and the latest Gazelle v1 is forward compatible: whichever version you're using, you can use a mix of extensions written against the v1 and v2 interfaces.
